# Vidhi Sahayak

Web interface for **Vidhi Sahayak**, an assistant for Delhi Police service matters and departmental enquiries.

This repository contains only the static chat page served by GitHub Pages. The assistant itself — the AI engine,
the document library and all data — runs on a private server; the page connects to it with an access key.
No documents, case data or keys are stored here.

Open the app: https://sherlyguides.github.io/vidhi-sahayak/
